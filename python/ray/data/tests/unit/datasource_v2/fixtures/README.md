# ORC Java string statistics fixture

`orc_java_strings.orc` is generated by `GenerateOrcStrings.java` with Apache ORC
Java 2.2.1 and JDK 17. It contains three forced stripes with embedded NUL,
non-ASCII/BMP/non-BMP strings, NULL and strings longer than the statistics
truncation threshold. No external dataset or user data is included.

To reproduce in a temporary directory (the writer must receive a new path):

```sh
curl -fLO https://repo.maven.apache.org/maven2/org/apache/orc/orc-tools/2.2.1/orc-tools-2.2.1-uber.jar
javac -cp orc-tools-2.2.1-uber.jar GenerateOrcStrings.java
java -cp .:orc-tools-2.2.1-uber.jar GenerateOrcStrings /tmp/orc_java_strings.orc
```

The ordinary tests read the checked-in fixture; Java is not a runtime or test
dependency. The generator also writes intermediate footers to flush stripes,
which are valid gaps between stripe ranges and must not be mistaken for data.
