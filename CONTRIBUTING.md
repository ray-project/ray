# Contributing to Ray

## Reporting bugs and asking questions

You can post questions or issues or feedback through the following channels:

1. [GitHub Issues](https://github.com/ray-project/ray/issues): For bug reports and feature requests.
2. [Discourse forum](https://discuss.ray.io/): For discussions about development and questions about usage.
3. [StackOverflow](https://stackoverflow.com/questions/tagged/ray)

## Finding issues to work on

We use GitHub labels to categorize issues and help contributors find work that matches their interests. See [What can I work on?](https://docs.ray.io/en/latest/ray-contribute/getting-involved.html#what-can-i-work-on) for a list of labels by component and type.

## To contribute a patch:

We welcome contributions! See [Getting Involved](https://docs.ray.io/en/latest/ray-contribute/getting-involved.html). To set up your development environment, see the [Setting up your development environment](https://docs.ray.io/en/latest/ray-contribute/getting-involved.html#setting-up-your-development-environment) section.

## PR Review Process

GitHub automatically requests reviews from the [CODEOWNERS](https://github.com/ray-project/ray/blob/master/.github/CODEOWNERS) of the files you change. Address their comments and re-request review until they approve. A committer then adds the `go` label to run the full CI, and the PR merges once CI passes. See [PR review process](https://docs.ray.io/en/latest/ray-contribute/getting-involved.html#pr-review-process) for details, and [AI-assisted contributions](https://docs.ray.io/en/latest/ray-contribute/getting-involved.html#ai-assisted-contributions) if you used an AI coding agent.
